# 💰 Wealth Predictor

> 一个基于 Python 的个人财富预测工具


## 📌 项目介绍

Wealth Predictor 是我的 Python + AI 90 Days 学习计划中的第一个完整项目。

通过输入个人财务信息，
帮助用户预测未来资产增长趋势。

---

## ✨ 当前功能

- 输入当前年龄
- 输入当前资产
- 输入每月收入
- 输入每月储蓄金额
- 计算未来资产变化
- 输出财富预测结果


---

## 🛠 技术栈

- Python
- 基础数据计算
- 用户输入交互
- 数据分析
