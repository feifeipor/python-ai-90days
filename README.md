# 💰 Wealth Predictor

## 项目简介

Wealth Predictor 是一个个人财富预测与分析系统。

用户可以输入个人财务信息，
系统会保存用户数据，并预测未来财富变化。


## ✨ 功能

### 👤 用户管理

- 添加用户
- 查看用户
- 保存用户数据


### ⭐ VIP用户

- 普通用户 / VIP用户区分
- VIP财富建议
- VIP预测模型


### 📈 财富预测

根据：

- 当前资产
- 月收入

计算：

- 未来10年预测资产


### 📄 自动报告

自动生成财富分析报告：

包含：

- 用户信息
- 用户等级
- 当前资产
- 月收入
- 未来预测
- 财富建议
